WinSidebar — Windows 10/11 x64

DOWNLOAD AND RUN
Download the ZIP from the official release and extract it into a folder you control. Double-click WinSidebar.exe. No installer, PowerShell, Git, or separate .NET download is needed.

IMPORTANT ABOUT OLDER RELEASES
The existing v1.0.0 release contains a Portuguese-language executable and a Portuguese LEIA-ME.txt. These English instructions are for future packages and do not change the previously published ZIP. English instructions for the existing release are at:
https://github.com/hamthet/WinSidebar/blob/main/docs/i18n/QUICK-START.en-US.md

CONTROLS
Click the narrow sidebar tab to expand or collapse it. Shift+F1 toggles the sidebar; Shift+F2 and Shift+F3 move between windows; Shift+F4 activates the selected window. Double-clicking a window also activates it. The header buttons move the sidebar to the opposite edge, decrease or increase its width, and exit (red X). Use the sidebar context menu to select a monitor when available.

FOUR CUSTOMIZABLE SHORTCUTS
Click the gear in the FOLDERS / WEB section and then a shortcut to edit its name, destination, type, icon, and browser. Save, then click the gear again to leave configuration mode. Changing the shortcut browser does not change the Windows default browser.

SECURITY AND PRIVACY
The executable is not digitally signed. Microsoft Defender SmartScreen or your IT policy may warn or block it. Download only from the official release and respect your computer's security policies. Compare the download to SHA256SUMS.txt if desired; a checksum does not replace a digital signature. Settings are stored under %LOCALAPPDATA%\WinSidebar. The program does not enable automatic startup or send telemetry. Close other sidebar editions before running this one to avoid global-hotkey conflicts.

REMOVAL
Quit using the red X and delete WinSidebar.exe. Optionally delete %LOCALAPPDATA%\WinSidebar to remove preferences and customized shortcuts for this edition.
