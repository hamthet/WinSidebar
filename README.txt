WinSidebar 2.0.0 - Windows 10/11 x64

INSTALL
Extract the ZIP to a folder you control and run WinSidebar.exe.
No installer or separate .NET download is required. The .NET 8 runtime is bundled.
The executable is unsigned; Windows SmartScreen or organizational policy may warn.

FIRST RUN
English is selected by default on a new profile.
Available languages: English, Brazilian Portuguese, Spanish, Russian, Simplified Chinese.
Your explicit choice is saved under %LOCALAPPDATA%\WinSidebar.

ESSENTIAL CONTROLS
AltGr+Y: toggle the sidebar.
F1-F4: open shortcuts 1-4.
Shift+F1-F4: default snippet hotkeys 1-4.
Shortcuts: left-click opens; right-click edits.
Scripts/snippets: click to paste; gear edits name, text and hotkey.
Use +, - and Restore independently in the Shortcuts and Scripts sections.

WINDOWS
Click a listed window to activate it.
Right-click a window for temporary Rename/Reset Name or to ignore that application.
Ignored applications can be managed from the general context menu.

DATA
Profile: %LOCALAPPDATA%\WinSidebar
WinSidebar does not enable automatic startup, change the default browser or send telemetry.
Snippet paste temporarily uses the Windows clipboard and attempts to restore it afterward.

REMOVE
Exit WinSidebar and delete WinSidebar.exe.
Delete %LOCALAPPDATA%\WinSidebar only if you also want to remove saved preferences.
