# Getting help with WinSidebar 2.0

[Português](docs/i18n/SUPPORT.pt-BR.md) · [Español](docs/i18n/SUPPORT.es-ES.md) · [Русский](docs/i18n/SUPPORT.ru-RU.md) · [简体中文](docs/i18n/SUPPORT.zh-CN.md)

You do not need to be technical to report a problem.

## Before reporting

1. Confirm that you extracted the ZIP before opening WinSidebar.exe.
2. Confirm that the problem still happens after closing and reopening WinSidebar.
3. Keep your saved profile if possible. Do not delete it just to make the error disappear.
4. Copy the exact error message if one is shown.

## What to tell us

Describe:
- what you clicked or which hotkey you pressed;
- what you expected;
- what happened instead;
- Windows 10 or Windows 11;
- which WinSidebar language you selected;
- whether you use more than one monitor;
- for paste problems, whether the target program was running as administrator.

A short step-by-step description is more useful than technical terminology.

## Protect your private data

WinSidebar can store private paths and text under `%LOCALAPPDATA%\WinSidebar`.

Before posting any file publicly, review it first. In particular:
- `shortcuts.xml` can contain local folder paths and website addresses;
- `snippets.json` can contain your saved text;
- `ignored-apps.json` can contain application paths;
- copied custom icons may reveal filenames or branding.

Do not post passwords, credentials, confidential text or private paths. A screenshot can also expose private information.

## Where to report

Use the repository's **Bug report** form under GitHub Issues. If you are unsure whether something is a bug, describe what happened; the form is written for normal users.

For common questions first see the [FAQ](docs/FAQ.md).
