## Короткий вариант объявления

WinSidebar 2.0 — переносимая боковая панель для Windows 10/11 x64: переключение между окнами, до 12 ярлыков и до 8 повторно используемых текстовых фрагментов. Программа распространяется как один самодостаточный исполняемый файл, поддерживает английский, бразильский португальский, испанский, русский и упрощённый китайский; для нового профиля по умолчанию выбран английский.

Основные команды: AltGr+Y открывает/сворачивает панель, F1–F4 запускают ярлыки 1–4, Shift+F1–F4 — стандартные клавиши текстовых фрагментов.

## Формулировки, которые должны оставаться точными

- Переносимое и самодостаточное приложение не означает наличие цифровой подписи.
- Runtime .NET 8 встроен.
- Поддерживаются пять языков; для нового профиля по умолчанию используется английский.
- Текстовые фрагменты не исполняют скрипты.
- Обнаружение окон эвристическое; не заявляйте точное совпадение с Alt+Tab.
- WinSidebar не отправляет телеметрию, не меняет браузер по умолчанию и не включает автозапуск.
