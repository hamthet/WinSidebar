WinSidebar 2.0.0 - Windows 10/11 x64

INSTALAR
Extrae el ZIP en una carpeta bajo tu control y ejecuta WinSidebar.exe.
No hace falta instalador ni descargar .NET por separado. El runtime .NET 8 está incluido.
El ejecutable no está firmado; Windows SmartScreen o las políticas de la organización pueden advertir.

PRIMER INICIO
English es el idioma predeterminado de un perfil nuevo.
Idiomas: inglés, portugués de Brasil, español, ruso y chino simplificado.
La elección explícita se guarda en %LOCALAPPDATA%\WinSidebar.

CONTROLES ESENCIALES
AltGr+Y: abre/cierra la barra.
F1-F4: abren los accesos directos 1-4.
Shift+F1-F4: atajos predeterminados de los fragmentos 1-4.
Accesos directos: clic izquierdo abre; clic derecho edita.
Scripts/fragmentos: clic pega; el engranaje edita nombre, texto y atajo.
Usa +, - y Restaurar de forma independiente en Accesos directos y Scripts.

VENTANAS
Haz clic en una ventana para activarla.
Clic derecho: renombrado temporal/restablecer nombre o ignorar la aplicación.
Las aplicaciones ignoradas se administran desde el menú contextual general.

DATOS
Perfil: %LOCALAPPDATA%\WinSidebar
WinSidebar no habilita inicio automático, no cambia el navegador predeterminado y no envía telemetría.
El pegado de fragmentos usa temporalmente el portapapeles e intenta restaurarlo después.

ELIMINAR
Cierra WinSidebar y elimina WinSidebar.exe.
Elimina %LOCALAPPDATA%\WinSidebar solo si también quieres borrar las preferencias guardadas.
