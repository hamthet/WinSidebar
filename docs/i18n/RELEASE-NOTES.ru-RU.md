# Примечания к выпуску WinSidebar 2.0

[English](../RELEASE-NOTES.md) · [Português](RELEASE-NOTES.pt-BR.md) · [Español](RELEASE-NOTES.es-ES.md) · [简体中文](RELEASE-NOTES.zh-CN.md)

Версия 2.0 — крупное обновление продукта.

## Основное

- Полный интерфейс на английском, бразильском португальском, испанском, русском и упрощённом китайском.
- Для новой установки по умолчанию используется английский; выбор сохраняется.
- Один самодостаточный исполняемый файл .NET 8 для Windows x64.
- От 4 до 12 настраиваемых ярлыков с независимыми кнопками добавления, удаления и сброса.
- От 4 до 8 текстовых фрагментов с независимыми элементами управления.
- Горячие клавиши фрагментов: Нет или Shift+F1…Shift+F12; для первых четырёх по умолчанию Shift+F1–F4.
- F1–F4 открывают ярлыки 1–4.
- AltGr+Y открывает/сворачивает панель.
- Редактирование ярлыка правым щелчком.
- Контекстное меню окна: временное переименование/сброс и постоянное игнорирование приложения.
- Сохраняемые ширина, высота и сторона панели.
- README, руководство, быстрый старт, материалы для публикации и концепт-арт на пяти языках.

## Совместимость

Старая навигация окон через Shift+F удалена. Старые профили без сохранённого языка могут оставаться на португальском до явного выбора. Миграция настроек между версиями не входит в проверку 2.0.

## Безопасность и распространение

Исполняемый файл переносимый и не имеет цифровой подписи. SmartScreen или политика организации могут показать предупреждение. WinSidebar не включает автозапуск, не меняет браузер по умолчанию и не отправляет телеметрию.

Текстовые фрагменты временно используют буфер обмена и пытаются восстановить его прежнее содержимое.
