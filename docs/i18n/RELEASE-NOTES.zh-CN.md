# WinSidebar 2.0 发布说明

[English](../RELEASE-NOTES.md) · [Português](RELEASE-NOTES.pt-BR.md) · [Español](RELEASE-NOTES.es-ES.md) · [Русский](RELEASE-NOTES.ru-RU.md)

2.0 是一次重要的产品升级。

## 主要变化

- 完整支持英语、巴西葡萄牙语、西班牙语、俄语和简体中文。
- 全新安装默认使用英语；用户选择会保存。
- Windows x64 单个自包含 .NET 8 可执行文件。
- 4–12 个可配置文件夹/网站快捷方式，增加、删除、恢复相互独立。
- 4–8 个纯文本片段，拥有独立控制。
- 文本片段快捷键可为无快捷键或 Shift+F1 到 Shift+F12；前四个默认 Shift+F1–F4。
- F1–F4 打开快捷方式 1–4。
- AltGr+Y 打开/收起侧边栏。
- 右键编辑快捷方式。
- 窗口菜单支持临时重命名/恢复以及持久忽略应用。
- 侧边栏宽度、高度和所在侧会保存。
- README、教程、快速入门、发布指南和概念插图均提供五种语言版本。

## 兼容性

旧版 Shift+F 窗口导航已移除。没有保存语言字段的旧配置可能继续使用葡萄牙语，直到用户明确选择其他语言。跨版本偏好迁移不属于 2.0 的验证范围。

## 安全与发布

可执行文件为便携式且未进行数字签名。SmartScreen 或组织策略可能显示警告。WinSidebar 不会设置自动启动，不会更改默认浏览器，也不会发送遥测数据。

文本片段粘贴会临时使用剪贴板，并在完成后尝试恢复原内容。
