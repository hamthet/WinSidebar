WinSidebar 2.0 - Windows 10/11 x64

УСТАНОВКА
Распакуйте ZIP в доступную вам папку и запустите WinSidebar.exe.
Установщик и отдельная загрузка .NET не нужны. Runtime .NET 8 включён.
Файл не имеет цифровой подписи; Windows SmartScreen или политика организации могут показать предупреждение.

ПЕРВЫЙ ЗАПУСК
Для нового профиля по умолчанию выбран English.
Языки: английский, бразильский португальский, испанский, русский, упрощённый китайский.
Явный выбор сохраняется в %LOCALAPPDATA%\WinSidebar.

ОСНОВНЫЕ КОМАНДЫ
AltGr+Y: открыть/свернуть панель.
F1-F4: открыть ярлыки 1-4.
Shift+F1-F4: стандартные клавиши фрагментов 1-4.
Ярлыки: обычный щелчок открывает, правый — редактирует.
Скрипты/фрагменты: щелчок вставляет, шестерёнка редактирует имя, текст и горячую клавишу.
+, - и Восстановить работают независимо в разделах ярлыков и скриптов.

ОКНА
Щёлкните окно в списке, чтобы активировать его.
Правый щелчок: временное переименование/сброс имени или игнорирование приложения.
Игнорируемые приложения управляются из общего контекстного меню.

ДАННЫЕ
Профиль: %LOCALAPPDATA%\WinSidebar
WinSidebar не включает автозапуск, не меняет браузер по умолчанию и не отправляет телеметрию.
Вставка фрагментов временно использует буфер обмена и пытается восстановить его после операции.

УДАЛЕНИЕ
Закройте WinSidebar и удалите WinSidebar.exe.
Удаляйте %LOCALAPPDATA%\WinSidebar только если хотите также стереть сохранённые настройки.
