# Como pedir ajuda com o WinSidebar 2.0

[English](../../SUPPORT.md) · [Español](SUPPORT.es-ES.md) · [Русский](SUPPORT.ru-RU.md) · [简体中文](SUPPORT.zh-CN.md)

Você não precisa entender de programação para relatar um problema.

## Antes de relatar

1. Confirme que extraiu o ZIP antes de abrir WinSidebar.exe.
2. Feche e abra o WinSidebar e veja se o problema se repete.
3. Preserve seu perfil salvo sempre que possível. Não o apague só para fazer o erro desaparecer.
4. Se houver mensagem de erro, copie o texto exato.

## O que informar

Conte:
- o que você clicou ou qual hotkey usou;
- o que esperava que acontecesse;
- o que aconteceu de fato;
- se usa Windows 10 ou Windows 11;
- qual idioma escolheu no WinSidebar;
- se usa mais de um monitor;
- em problemas de colagem, se o programa de destino estava aberto como administrador.

Uma descrição simples, passo a passo, é melhor do que termos técnicos.

## Proteja seus dados

O WinSidebar pode guardar caminhos e textos privados em `%LOCALAPPDATA%\WinSidebar`.

Antes de publicar qualquer arquivo, revise o conteúdo. Em especial:
- `shortcuts.xml` pode conter caminhos locais e endereços de sites;
- `snippets.json` pode conter textos salvos;
- `ignored-apps.json` pode conter caminhos de aplicativos;
- ícones personalizados podem revelar nomes ou marcas.

Não publique senhas, credenciais, textos confidenciais ou caminhos privados. Capturas de tela também podem expor informações.

## Onde relatar

Use o formulário **Bug report** em GitHub Issues. Se não souber se é realmente um bug, descreva o que aconteceu; o formulário foi feito para usuários comuns.

Para dúvidas frequentes, consulte primeiro as [perguntas frequentes](FAQ.pt-BR.md).
