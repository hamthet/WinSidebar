# Руководство WinSidebar 2.0

[README](README.ru-RU.md) · [English](../../docs/TUTORIAL.md) · [Português](TUTORIAL.pt-BR.md) · [Español](TUTORIAL.es-ES.md) · [简体中文](TUTORIAL.zh-CN.md)

## 1. Запуск переносимого приложения

Распакуйте ZIP WinSidebar 2.0 и запустите WinSidebar.exe. Установщик и отдельный runtime .NET не требуются.

Для полностью нового профиля предварительно выбран English. При первом запуске также доступны Português (Brasil), Español, Русский и 简体中文. Выбор сохраняется в %LOCALAPPDATA%\WinSidebar.

Если Windows показывает SmartScreen, учитывайте, что текущий исполняемый файл не имеет цифровой подписи. Соблюдайте политику безопасности вашей организации.

## 2. Открытие и сворачивание панели

Нажмите узкую вкладку у края экрана или AltGr+Y.

AltGr+Y переключает оба состояния: свёрнутая панель открывается, открытая сворачивается.

Кнопки заголовка позволяют перенести панель на другую сторону и циклически менять ширину и высоту. Выбор сохраняется.

## 3. Переключение окон

Откройте панель и щёлкните подходящее окно. Окна группируются по мониторам.

Правый щелчок по окну:

- Переименовать — временная метка для текущего живого окна;
- Сбросить имя — удалить временную метку;
- Игнорировать приложение — постоянно скрывать окна этого приложения.

Общее контекстное меню позволяет управлять игнорируемыми приложениями.

Обнаружение основано на метаданных и эвристиках Windows; список может не полностью совпадать с системным Alt+Tab.

## 4. Настройка ярлыков

Раздел ярлыков начинается с четырёх элементов.

- Обычный щелчок: открыть.
- Правый щелчок: редактировать.
- +: добавить строку из четырёх.
- −: удалить последнюю добавленную строку, но не ниже четырёх.
- Восстановить: сбросить только ярлыки.

Максимум — 12 ярлыков.

Редактор задаёт имя, цель, тип, браузер и значок. Пользовательские значки копируются в профиль.

F1–F4 глобально открывают ярлыки 1–4. Остальные используются мышью.

## 5. Настройка текстовых фрагментов

Раздел Скрипты хранит буквальный текст, а не исполняемый код.

- Щелчок по строке: вставить текст в последнее подходящее внешнее приложение.
- Шестерёнка: редактировать имя, содержимое и горячую клавишу.
- +: добавить фрагмент.
- −: удалить последний, но не ниже четырёх.
- Восстановить: сбросить только фрагменты.

Максимум — 8.

Для фрагментов 1–4 по умолчанию назначены Shift+F1–F4. Любой фрагмент может использовать Нет или Shift+F1…Shift+F12. Дубликаты запрещены.

Для вставки временно используется буфер обмена, затем WinSidebar пытается восстановить прежнее содержимое. Windows может блокировать имитацию ввода в приложения с повышенными правами.

## 6. Смена языка

В общем контекстном меню выберите Язык. Доступны English, Português (Brasil), Español, Русский и 简体中文.

Выбор сохраняется в settings.ini.

Новая установка всегда начинает с английского независимо от языка Windows. Старые профили без сохранённого языка могут сначала оставаться на португальском.

## 7. Файлы профиля

Состояние хранится в:

    %LOCALAPPDATA%\WinSidebar

В папке могут быть settings.ini, shortcuts.xml, snippets.json, ignored-apps.json, icons\ и файлы .bak.

Пользовательские имена, пути, тексты фрагментов и заголовки внешних окон не переводятся.

## 8. Восстановление

Сброс ярлыков и сброс скриптов независимы.

Если файл профиля повреждён, сохраните оригинал перед ручным удалением или заменой: он может понадобиться для восстановления данных.

Миграция настроек между версиями не входит в контракт проверки 2.0.

## 9. Удаление

Закройте WinSidebar и удалите WinSidebar.exe и документацию из ZIP.

Профиль независим. Удаляйте %LOCALAPPDATA%\WinSidebar только если хотите стереть сохранённые данные.

## 10. Клавиатура

| Команда | Действие |
| --- | --- |
| AltGr+Y | Открыть/свернуть панель |
| F1–F4 | Открыть ярлыки 1–4 |
| Shift+F1–F4 | Стандартные клавиши фрагментов 1–4 |
| Shift+F1–F12 | Доступные настраиваемые клавиши |

Старая навигация по окнам через Shift+F намеренно удалена в 2.0.
