# WinSidebar 2.0 教程

[README](README.zh-CN.md) · [English](../../docs/TUTORIAL.md) · [Português](TUTORIAL.pt-BR.md) · [Español](TUTORIAL.es-ES.md) · [Русский](TUTORIAL.ru-RU.md)

## 1. 启动便携应用

解压 WinSidebar 2.0 ZIP，然后运行 WinSidebar.exe。无需安装程序，也无需单独安装 .NET runtime。

在全新配置文件中会预选 English。首次启动还可选择 Português (Brasil)、Español、Русский 和 简体中文。选择会保存到 %LOCALAPPDATA%\WinSidebar。

如果 Windows 显示 SmartScreen 警告，请注意当前可执行文件未进行数字签名，并遵循组织的安全策略。

## 2. 打开和收起侧边栏

可点击屏幕边缘的窄标签，或按 AltGr+Y。

AltGr+Y 是双向切换：收起时打开，打开时收起。

顶部按钮可把侧边栏移到另一侧，并循环调整宽度和高度。这些设置会保存。

## 3. 切换窗口

打开侧边栏并点击符合条件的窗口。WinSidebar 按显示器分组。

右键窗口可使用：

- 重命名 — 为当前活动窗口设置临时标签；
- 恢复名称 — 删除临时标签；
- 忽略此应用 — 持久隐藏该应用的窗口。

通用右键菜单可管理已忽略的应用并重新显示。

窗口发现依赖 Windows 元数据和启发式判断，因此可能与系统 Alt+Tab 列表并不完全一致。

## 4. 配置快捷方式

快捷方式部分默认有 4 个项目。

- 左键：打开目标。
- 右键：编辑。
- +：增加一行 4 个。
- −：删除最后增加的一行，但不会少于 4 个。
- 恢复：只恢复快捷方式。

最多 12 个快捷方式。

编辑器可设置名称、目标、类型、浏览器和图标。自定义图标会复制到 WinSidebar 配置文件。

F1–F4 全局打开快捷方式 1–4，其余通过鼠标使用。

## 5. 配置文本片段

脚本部分保存纯文本，不执行代码。

- 点击行：把保存的文本粘贴到最近的符合条件的外部应用。
- 齿轮：编辑名称、内容和快捷键。
- +：增加一个片段。
- −：删除最后增加的片段，但不会少于 4 个。
- 恢复：只恢复片段。

最多 8 个文本片段。

片段 1–4 默认使用 Shift+F1–F4。每个片段可设置为无快捷键或 Shift+F1 到 Shift+F12，不允许重复。

粘贴时会临时使用 Windows 剪贴板，完成后尝试恢复原内容。Windows 可能阻止向高权限应用模拟输入。

## 6. 更改语言

打开通用右键菜单并选择语言。支持 English、Português (Brasil)、Español、Русский 和 简体中文。

选择保存在 settings.ini。

全新安装始终从英语开始，不受 Windows 显示语言影响。没有保存语言字段的旧配置可能最初继续使用葡萄牙语。

## 7. 配置文件

用户状态保存在：

    %LOCALAPPDATA%\WinSidebar

文件夹中可能包含 settings.ini、shortcuts.xml、snippets.json、ignored-apps.json、icons\ 和 .bak 备份。

用户输入的名称、路径、文本片段和外部窗口标题不会被翻译。

## 8. 恢复与修复

恢复快捷方式与恢复脚本相互独立。

如果配置文件无法读取，在手动删除或替换前请先保留原文件；它可能对数据恢复有帮助。

跨版本偏好迁移不属于 2.0 的验证合同。

## 9. 删除

退出 WinSidebar，然后删除 WinSidebar.exe 和解压出的文档。

配置文件相互独立。只有在同时希望清除已保存数据时才删除 %LOCALAPPDATA%\WinSidebar。

## 10. 键盘参考

| 按键 | 操作 |
| --- | --- |
| AltGr+Y | 打开/收起侧边栏 |
| F1–F4 | 打开快捷方式 1–4 |
| Shift+F1–F4 | 文本片段 1–4 的默认快捷键 |
| Shift+F1–F12 | 可配置的文本片段快捷键 |

2.0 已有意移除旧版 Shift+F 窗口列表导航。
